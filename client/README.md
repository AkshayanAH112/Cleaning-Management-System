# Cleaning Management System – Client

This is the frontend for the Cleaning Management System, built with React, Vite, Tailwind CSS, and Material UI.

## Features

- Book cleaning services
- View and manage your bookings
- Responsive and modern UI
- Uses REST API to communicate with the backend

## Getting Started

### Prerequisites

- Node.js (v16+ recommended)
- npm or yarn

### Installation

```sh
npm install
```

### Running the Client

```sh
npm run dev
```

The app will be available at [http://localhost:5173](http://localhost:5173).

- Edit pages in `src/pages/`
- Styling via Tailwind CSS and MUI

## Environment

- The client expects the backend API to be running at `http://localhost:5000`
